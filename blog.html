❀ 2026.05.08 LATEST FEELINGS

第○話のこのシーンが好きすぎる

感情がぐちゃぐちゃになるやつ。言葉にできないけど、なんかもう、ここだよここ。見るたびに違う気持ちになる。最初は悲しいと思ってたのに、2周目は全然違って見えた。

READ MORE → 感情 🌿

最初に見たとき、あのシーンで普通に泣いてしまった。こんなに泣く予定じゃなかった。ただのファンタジーアニメのつもりで見てたのに、いつの間にか全力で感情移入してた。

表情の作り方がすごくて、ちゃんと言葉で説明してくれないけど伝わってくる。あの間とか、目線の動きとか。スタッフが分かってる感じがする。原作読んだとき脳内で想像してたより全然良かった。

何回見ても飽きないし、むしろ見るたびに新しい発見がある。解像度が上がっていく感じ、好き。

✾ 2026.04.30 EXPRESSION

この表情なんなんだろう

分からないけどめちゃくちゃ好き。言語化しようとするほど逃げていく気がする。ただただ「良い」としか言えない。なんでこんなに刺さるんだろう。

READ MORE → 感覚 ❀

これは本当に難しい。あの表情を見た瞬間に「分かる」ってなるんだけど、「何が分かるの？」って聞かれると答えられない。

たぶん言語化できない感情をそのまま映像にしてくれてる、みたいな感じがするのかもしれない。見た目の話じゃなくて、もっと内側の何かが。

この感覚を誰かと共有したいんだけど、伝わるか微妙。同じように感じてる人いたら嬉しい。

❀ 2026.04.18 MUSIC

OPの入り方が毎回ずるい

あの瞬間に音楽が来るのは計算されてると思う。引きずり込まれる。OPスキップできない人間なので毎話まるごと見てしまう。

READ MORE → 音楽 ✾

映像と音楽のタイミングが完全に一致してる瞬間が好きすぎて。あそこでそのメロディーが来るのは反則。

OPって全部見る派なんだけど、このアニメは特に毎回ちゃんと見てしまう。同じOPなのに話数によって受け取り方が変わるのが面白い。伏線を知った後に見ると全部違って見える。

✾ 2026.04.05 ART

ファンアートを描き始めた話

絵が上手くなりたい気持ちになったのは久しぶりで、それだけでこの作品のことが好きなんだと思う。うまく描けなくてもいいから記録しておきたい。

READ MORE → 制作 🌸

久しぶりに絵を描きたくなった。何かを描きたい、という気持ちになったのが何年ぶりかも分からないくらい久しぶりで、それが自分でも驚いた。

うまく描けなくてもいい。好きなキャラクターを、好きなシーンを、自分の手で残したい。そういう気持ちでこのサイトも作り始めた気がする。

ギャラリーに少しずつ追加していくつもりです。恥ずかしいけど。
